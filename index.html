About This Intelligence Feed

Welcome to Artifact Radar. This system monitors the global antiquities market to identify potentially illicit trafficking of cultural artifacts.

Historical Source Monitoring

Artifact Radar keeps an observation history for monitorable source URLs. A record remains in the dataset even when its source later becomes unavailable, so the dashboard can show that the source was previously observed.

Important: a 404/410 response is recorded as “Source disappeared”; it does not by itself prove intentional deletion, illicit activity, or wrongdoing. A 403/429/5xx response or timeout is recorded as “Unavailable”. A changed content signature is a technical signal and can be caused by legitimate edits, dynamic content, advertising, localisation, or site redesign.

When “Inspect Source” is unavailable

A disabled source button means Artifact Radar does not currently have a reliable direct page to open. This can happen when only a temporary search-grounding redirect was captured, when the source has returned 404/410, or when the source is currently unreachable or blocking automated checks. It is not, by itself, evidence that the underlying information was false or intentionally removed.

V7 Evidence Snapshots

For monitorable HTML sources, Artifact Radar stores compact structured snapshots and keeps up to 12 distinct observed states per fingerprint. The system compares page title, description, images, page price metadata, provenance-related text, evidence scores and final URLs. A detected difference is an observation of change, not proof of intentional editing or wrongdoing.

Risk Scoring Methodology

  • High Evidence Score (8–10): Multiple observed risk signals combine to produce a deterministic evidence score; this is not proof of illicit activity.
  • Medium Evidence Score (4–7): Some observed risk signals are present, with the same requirement for human verification.

Export Feature

The Export XML button generates a Dublin Core compliant metadata file of all currently-filtered listings. Dublin Core (DC) is the international standard (ISO 15836) used by libraries, archives, and cultural heritage institutions to describe digital resources.

Pagination & Filters

Use the filter bar to narrow by status, platform category, and provenance. Select 10–100 items per page to prevent performance issues as the dataset grows. Sorting and text search work across all filtered results.
